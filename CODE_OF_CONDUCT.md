# Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

Unacceptable behavior includes: sexualized language or imagery, trolling, insulting comments, personal attacks, publishing others' private information without permission, and any conduct that would reasonably be considered inappropriate in a professional setting.

Report issues to the maintainers via the contact on the repository profile, or use [private vulnerability reporting](https://github.com/Demon-radio/Bemora.lol/security/advisories/new) for sensitive matters. Maintainers may remove contributions and ban repeat offenders.

Full version for package contributors: [`bemora/CODE_OF_CONDUCT.md`](bemora/CODE_OF_CONDUCT.md) (adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1).
