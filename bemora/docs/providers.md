# Providers

90+ namespaces hang off one `Bemora` instance. Naming convention: `api.<namespace>.<method>(params)`.

| Area             | Namespaces                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Weather / geo    | `weather`, `weatheralerts`, `location`, `ip`, `countries`, `astronomy`, `airquality`, `postal`                                                                                                                                                                                                                                                                                                         |
| Finance          | `currency`, `currencyHistory`, `crypto`, `coinWizard`, `gold`, `stocks`, `finance`, `govspending`, `worldbank`, `blockchain`                                                                                                                                                                                                                                                                           |
| News / research  | `news`, `research`, `wikidata`, `arxiv`, `books`, `literature`, `university`, `search`                                                                                                                                                                                                                                                                                                                 |
| Media            | `images`, `music`, `movies`, `tv`, `podcasts`, `art`, `anime`, `comics`                                                                                                                                                                                                                                                                                                                                |
| Social / dev     | `social`, `dev`, `stackexchange`, `websites`, `techdb`, `markdown`                                                                                                                                                                                                                                                                                                                                     |
| Science / health | `space`, `spaceExtended`, `covid`, `earthquake`, `medical`, `nutrition`, `disasters`, `biodiversity`                                                                                                                                                                                                                                                                                                   |
| Sports / games   | `football`, `sportsdb`, `baseball`, `hockey`, `basketball`, `gaming` (CrossFire, Fortnite, LoL, Minecraft, Chess)                                                                                                                                                                                                                                                                                      |
| AI               | `ai` (`groq`, `openai`, `anthropic`, `gemini`, `cohere`, `mistral`, `together`, `perplexity` + streaming)                                                                                                                                                                                                                                                                                              |
| Utilities        | `utils`, `smart`, `enriched`, `combined`, `free`, `rss`, `realtime`, `prayer`, `flights`, `jobs`, `vehicles`, `pets`, `drinks`, `geography`, `wildlife`, `politics`, `language`, `law`, `military`, `religion`, `islamic`, `thesaurus`, `fakedb`, `webtools`, `domain`, `placeholder`, `predict`, `brewery`, `fandom`, `spotify`, `steam`, `animals`, `lyrics`, `math`, `science`, `translate`, `food` |
| Enterprise       | `payments`, `email`, `sms`, `auth`, `jwt`, `storage`, `vectordb`, `sentry`, `notifications`, `maps`, `searchEnt`, `calendar`, `captcha`, `security`, `cloudflare`                                                                                                                                                                                                                                      |

> Removed in `1.0.0-alpha.1` (attack-surface reduction): `pokemon`, `rickmorty`, `starwars`, `harrypotter`, `chucknorris`, `bored`, `kanye`, `dadjokes`, `advice`, `randomuser`, `fun`, `memes`, `zodiac`. They are also gone from the MCP catalog.

Adding a provider: 3 edits (`import` + constructor `this.x = this._buildX()` + `_buildX()` block in `src/index.js`) plus an MCP entry in `src/mcp-server/provider-info.js`. Full guide in [CONTRIBUTING.md](../CONTRIBUTING.md).
